# Firewall-Centric Network Security and Insider Threat Detection

## Overview
This project proposes a firewall-centric intelligent network security system capable of detecting both external cyber attacks and insider threats using machine learning and explainable AI.

## Features
- Multi-protocol traffic analysis (HTTP, TCP, UDP, FTP, SMTP)
- Payload-based attack detection
- Insider threat detection using user behavior analysis
- Isolation Forest for anomaly detection
- Random Forest for supervised attack classification
- Explainable AI using SHAP and LIME
- Streamlit dashboard for visualization
